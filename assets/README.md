# Assets

Optional images for the Focus Room.

## Break / community image

Add a file named `break-image.jpg` here to show a calm image during break
blocks and the Community / Reset block of the 2-hour live session.

- Path is set by `BREAK_IMAGE` near the top of the `<script>` in `index.html`
  (default: `assets/break-image.jpg`).
- If the file is missing, the app shows a soft gradient placeholder instead —
  nothing breaks.
- Landscape images (e.g. 1280×720) look best in the side panel.
